## 🐉 The Bestiary — Dragons I Have Slain

Every explorer is measured by the monsters met. These are mine, each from a real battle.

| Dragon | Where I met it | How it was slain |
|---|---|---|
| 🐍 **The NaN Serpent** | `float has no attribute 'lower'` while cleaning 50k reviews | `isinstance(text, str)` guards and `fillna('')` after every CSV load |
| 🐙 **The Imbalance Hydra** | 64% of reviews were 5-star, so the negative class starved | Stratified splits, per-class F1, and `class_weight` as the next weapon |
| 🪞 **The Accuracy Mirage** | 89% accuracy hiding a negative F1 of 0.71 | Never trust accuracy alone; read precision, recall and F1 per class |
| 👻 **The Domain-Drift Wraith** | spaCy tagged "LOVED" and "Vanilla" as organisations | Post-filtering the entities; a news-trained model needs a food-review reality check |
| 🌀 **The Kernel Labyrinth** | spaCy "installed" yet `ModuleNotFoundError` | `sys.executable -m pip` installs straight into the exact Python Jupyter runs |
